## Sobre o Projeto
Aplicação Web desenvolvida no padrão arquitetural **MVC (Model-View-Controller)** para controle de abertura de turnos, lançamento de entradas/saídas e conferência automática de fechamento de caixa.

## Tecnologias Utilizadas
* **Back-end:** Node.js + Express
* **Front-end:** HTML5, CSS3, JavaScript (EJS Templates)
* **Banco de Dados:** SQLite3
* **Arquitetura:** MVC (Model-View-Controller)

## Estrutura de Pastas
* `/docs`: Documentação técnica atualizada (Requisitos, Diagramas UML, Projeto Físico SQL e Dicionário de Dados).
* `/src`: Código-fonte da aplicação dividido em `models`, `views`, `controllers` e `routes`.

## Como Executar Localmente
1. Entre na pasta `src`: `cd src`
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npm start`
4. Acesse no navegador: `http://localhost:3000`
